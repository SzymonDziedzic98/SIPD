Testy (odpowiedniki experiment … type: test)

Co odwzorowuje ten port

Plik sipd.py zawiera cały model z models/PD.gaml: sieć ścieżek, siatkę komórek z polem disorder, 9 charakterów, Q-learning per przeciwnik ze stanami RISKY/SAFE, pamięć społeczną i środowiskową, efekt rozbitej szyby, kotwicę charakteru, ograniczenie gier (height), limit Dunbara, typ gry, klasyczny start od C, metryki, eksporty CSV, eksperymenty batch i testy.

Różnice względem GAMA

  • Inny generator liczb losowych: wyniki zgadzają się statystycznie, nie liczba w liczbę. W obrębie tej wersji ten sam seed daje te same wyniki.
  • GeoJSON w stopniach jest rzutowany lokalnie na metry (GAMA używa UTM); różnica w skali parku jest pomijalna.
  • Ruch po sieci idzie krawędzią do sąsiedniego wierzchołka; wander w sztucznym świecie przy krawędzi losuje nowy kierunek.
  • Bez pliku drogi.geojson używana jest syntetyczna sieć parkowa 540 × 540 m.

Uruchamianie poza przeglądarką

python sipd.py --test, python sipd.py --experiment A_baseline --repeat 2 --end-cycle 2000 --geojson drogi.geojson. Stronę lokalnie: python -m http.server w katalogu web/, potem http://localhost:8000.
